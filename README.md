# Minigame 1
## Devlog
A metaphor I came up with about the relationship between Components, Game Objects, and Scenes is about a sandwich. The metaphor is the components are like all of the ingredients of the sandwich such as the bread, bacon, mayo etc. the game objects is the sandwich fully put together, and the scenes is the lunchbox and or other area the sandwich is placed. I really like this metaphor because it goes more into depth on how each section really impacts each other in the sequence. I can confidently say this is something I would say to another student, and I will most likely use this metaphor when explaining what I did in GDIM 31 to my parents.
